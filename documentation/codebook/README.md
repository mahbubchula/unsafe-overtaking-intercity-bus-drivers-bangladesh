# Master Codebook

`master-codebook.xlsx` is a byte-for-byte copy of the supplied `Codebook.xlsx`. It contains seven worksheets: Variable register, Response codes, Interviewer metadata, Derived variables, Response card guide, RQ and RO, and Outcome decision rules. No source PDF was supplied.

The workbook documents 45 item codes, variable descriptions, English and Bangla wording, response categories, recall periods, screening and skip rules, missing-value handling, the UO1–UO5 outcome derivation, F1 conditional representation, and the analytical roles of S1 and S2. Preserve all worksheets, formatting, documentation, and response definitions.
