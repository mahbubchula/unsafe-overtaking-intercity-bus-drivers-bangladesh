# Bayesian Analysis

This directory is reserved for the approved Bayesian logistic-regression workflow. The restricted primary model uses C2, D2, D3, E4, and F1. F1 requires separate representation of delayed-trip exposure and recovery pressure conditional on experiencing a delayed trip, producing six slope parameters from the five source questions.

Prior choices, diagnostics, sensitivity analyses, and reporting conventions must be aligned with Chapter 3 before implementation. No model has been fitted in this repository.
