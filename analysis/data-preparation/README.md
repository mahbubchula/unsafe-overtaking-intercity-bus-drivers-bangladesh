# Data Preparation

Future code in this directory should validate source schemas, apply eligibility rules based on A1–A6 and D1, derive the primary binary outcome from UO1–UO5, and preserve a clear distinction among genuine zero, inapplicability, structural skip, collection error, recall difficulty, and refusal.

Special codes are 95 (no relevant opportunity or stated inapplicability), 96 (structural skip), 97 (missing or incomplete due to collection error), 98 (cannot recall, estimate, or judge), and 99 (prefer not to answer). They must not enter calculations as numeric measurements.

Do not place source or processed participant data in this repository.
