# Bangla Questionnaire

`questionnaire-bn.docx` is a byte-for-byte copy of the supplied `Questionnaire_BN.docx`. The document labels itself a proposal-defense / expert-review and comprehension-testing copy and states that data collection must not begin before ethics approval and piloting. No matching source PDF was supplied.

The file contains the same 45-item code inventory as the English questionnaire and codebook. This confirms structural alignment only, not full translation equivalence. Do not describe this version as final or approved until semantic harmonization and the required review stages are documented.

The source uses `Noto Serif Bengali`. That font was unavailable to the bundled headless renderer during repository QA, so the Bengali glyph layout could not be visually certified in that environment. The source file was not altered or substituted.
